# InternHub - Responsive Internship Board

A responsive and accessible internship listing interface built using semantic HTML, CSS3 and Vanilla JavaScript.

## Project Overview

InternHub helps students discover internship opportunities across different domains such as Technology, Design, Marketing, Finance and Human Resources.

The project was created as part of a Full-Stack Development Internship task.

## Features

- Responsive design
- Mobile, tablet and desktop support
- Internship listing cards
- Search internships
- Domain filtering
- Clear filters
- Empty search results state
- Error state
- Retry functionality
- Keyboard-friendly interactions
- Accessible form labels
- Semantic HTML structure
- ARIA live regions
- Reduced-motion support
- Reusable internship data
- No frontend framework

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM API
- Responsive CSS
- Accessibility best practices
